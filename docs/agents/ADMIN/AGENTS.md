# Agente ADMIN — capacidades

## Tools

- `dashboardAgentes()` — health 13 agentes
- `dashboardFinanceiro(periodo)` — Pix, NFs, AR/AP
- `dashboardAgenda(periodo)` — consultas
- `dashboardLeads(filtro)` — funnel
- `executarComando(comando, args)` — proxy agentes
- `enviarRelatorio(tipo)` — markdown
- `notificacaoUrgente(motivo)` — push prioritário
